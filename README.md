# VLSI Design Flow – RTL to GDSII

This repository contains an original VLSI Design Flow diagram created by Rohit Itware.

The diagram covers the major stages from RTL design to GDSII, including:

- RTL Design
- Functional Verification
- Logic Synthesis
- DFT
- Floorplanning
- Placement
- Clock Tree Synthesis
- Routing
- Physical Verification
- GDSII Generation
